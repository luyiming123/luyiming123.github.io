## 为什么要写博客

在社交媒体上发一段话，和在博客上写一篇文章，是两种完全不同的行为。

前者的目标是被看见，后者的目标是**想清楚**。当我知道读者只有未来的自己和少数几个朋友时，我就不得不把话说完整：把「我觉得这个定理很神奇」展开成「它为什么神奇、它把哪个直觉推翻、我第一次读到它时哪里卡住了」。

写作是思考的显影液。很多我自以为懂了的证明，一动笔就发现中间缺了一环。这篇以及之后的所有文章，主要就是为了逼自己把那一环补上。

## 这个博客会写什么

大致是两条线：

**一、计算机科学理论。**

- 算法与数据结构里那些"漂亮"的想法
- 计算复杂性：P/NP、归约、近似与硬度
- 逻辑与形式化方法：类型论、证明助手（Lean / Coq）
- 概率与随机化算法

**二、大学生活。**

选课、阅读、拖延、期末、迷茫、以及偶尔的顿悟。这一类的文章会更主观，也更诚实。

## 关于技术选择

这个站点用 [Hugo](https://gohugo.io/) 构建，主题是 [PaperMod](https://github.com/adityatelange/hugo-PaperMod)，托管在 GitHub Pages 上，推送 Markdown 后由 GitHub Actions 自动发布。

选它的理由很朴素：**快、无依赖、纯静态**。没有数据库，没有服务器，没有需要维护的插件。哪怕五年后我忘了所有配置，只要 Markdown 文件还在，站点就还能重新构建出来。

> 一个只依赖文本的博客，寿命比任何框架都长。

## 接下来的计划

2. 把《算法导论》式的笔记整理成可检索的系列

如果你碰巧读到了某篇文章并发现了错误，欢迎到 [GitHub](https://github.com/YmingLu) 开 issue 指正 —— 这是我写博客的另一个重要原因。
